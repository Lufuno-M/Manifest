# Manifest

Manifest is a prototype for a single-object editorial homepage.

It treats each item like a cultural feature rather than a standard listing:

- one hero object at a time
- white gallery-style background
- silver / chrome / glass visual language
- subtle 3D motion
- verified facts separated from narrative and interpretation
- a quiet commerce action instead of a loud product grid

## Current prototype

The current HTML prototype includes:

- a fixed wordmark header
- a full-screen 3D hero stage
- drag-to-rotate interaction
- a facts layer that stays visible
- optional narrative and interpretation layers
- an understated Add to Bag action

## Notes

- Facts should only come from verified fields.
- Narrative should stay bounded to those verified fields.
- Interpretation should remain clearly labeled as opinion.
- Unknown values should stay unconfirmed rather than being invented.

## Files

- `index.html` — homepage prototype
- `manifest-ai-content-architecture.md` — content rules and generation logic

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.
