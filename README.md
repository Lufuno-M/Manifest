# Manifest

**Objects, recognized.**

Manifest is an experimental catalog of culturally recognized objects — presented as artifacts rather than conventional products.

Each object carries its own identity, imagery, context, and recognized value. The interface is intentionally spatial and atmospheric: objects float, move, change, and exist within the environment rather than inside a traditional storefront grid.

## What it is

* A curated catalog of recognizable objects
* Object-level identity rather than SKU-first commerce
* Research-informed recognized values
* Spatial, interactive presentation
* An evolving visual archive

Manifest is built to feel less like a store and more like **walking into a room of objects that already mean something.**

## Built with

HTML, CSS, and JavaScript.
